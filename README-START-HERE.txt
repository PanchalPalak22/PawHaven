PAWHAVEN - PET CARE WEBSITE

This folder contains the PawHaven website in a static HTML/CSS/JavaScript structure.
PawHaven is a pet care platform designed to help pet lovers explore puppies, pet services and useful information.

HOW TO OPEN IN VS CODE
1. Extract this ZIP file.
2. Open the extracted folder (pawhaven-website) in VS Code.
3. Install the “Live Server” extension if it is not installed.
4. Right-click the root index.html file and choose “Open with Live Server”.
5. Use the website navigation to open Puppies, Happy families, How it works, FAQ and Visit & contact.

IMPORTANT
- Keep the _next folder and all page folders together with index.html. They contain the website's CSS, JavaScript and images.
- Do not move individual HTML files out of their folders.
- The current website name is PawHaven. All website branding has been updated to PawHaven.
- WhatsApp, phone and email links use the details present in the supplied PawHaven source project.

This is a static website build, so it does not require npm install or a React development server.
